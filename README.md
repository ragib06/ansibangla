# ANSI Bangla

Convert ANSI Bangla (Bijoy / SutonnyMJ) PDFs and Word documents to Unicode, keeping their
formatting.

| Folder | What it is |
|--------|------------|
| [`python/`](python/) | The `ansibangla` Python package and command-line tool: PDF or `.docx` in, Unicode PDF, Word, EPUB or Markdown out. See its [README](python/README.md). |
| [`web/`](web/) | A static web app that runs the same package in the browser (Pyodide); PDFs come from the browser's print dialog. See its [README](web/README.md). |
| `sample/` | Your own test files (ignored by git; sample books are usually copyrighted). Both test suites use it. |

*Bijoy and SutonnyMJ are names of their owners; this project is not affiliated with them.*
